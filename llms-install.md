# Установка moysklad-mcp-ru агентом

Документ для ИИ-агента, который ставит сервер за человека. Человеку удобнее
[README](README.md).

## 1. Проверить uv

```bash
uvx --version || curl -LsSf https://astral.sh/uv/install.sh | sh
```

## 2. Прописать сервер

Claude Desktop: `~/Library/Application Support/Claude/claude_desktop_config.json`
(macOS) или `%APPDATA%\Claude\claude_desktop_config.json` (Windows).
Cline: `cline_mcp_settings.json`.

```json
{
  "mcpServers": {
    "ms": {
      "command": "uvx",
      "args": ["--from", "moysklad-mcp-ru", "ms-mcp"],
      "env": {
        "MOYSKLAD_TOKEN": "<токен кабинета>"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```

## 3. Токен

| переменная | тип | где взять |
|---|---|---|
| `MOYSKLAD_TOKEN` | секрет | МойСклад → Настройки → Пользователи → Токены доступа |

Значение спрашивается у человека и в репозиторий не пишется. Второй путь, без
переменных окружения: запустить сервер и вызвать `ms_add_cabinet`, токен ляжет
в `~/.moysklad-mcp/cabinets.json` с правами 600. Кабинетов подключается
сколько нужно, переключение через `ms_use_cabinet`.

## 4. Проверить

Перезапустить клиент и вызвать `ms_ping`. Каталог отвечает
`ms_search_methods`, в нём 892 метода JSON API 1.2.

## 5. Запись выключена, и включать её молча нельзя

Чтение работает сразу. Запись требует ДВУХ независимых условий:

1. процессный guard `MOYSKLAD_ALLOW_WRITE=1` в окружении сервера, по умолчанию
   выключен;
2. `confirm_write=true` в самом вызове, а для проведения и удаления ещё и
   `i_understand_this_modifies_data=true`.

Токен кабинета двигает остатки и деньги. Не выставляй `MOYSKLAD_ALLOW_WRITE=1`
по своей инициативе и не направляй его на боевой кабинет: сначала тестовый,
и только с явного согласия человека. Пин к конкретному кабинету делается через
`MOYSKLAD_WRITE_CABINETS`. Создание документа всегда даёт ЧЕРНОВИК
(`applicable:false`), проведение это отдельный шаг.

## Если не поднимается

- `uvx` не найден: шаг 1, потом перезапустить клиент, он читает PATH при старте.
- Пусто в списке инструментов: клиент не перечитал конфигурацию, нужен рестарт.
- Необъяснимый 401 при верном токене: активный кабинет в
  `~/.moysklad-mcp/cabinets.json` имеет приоритет над переменной окружения.
  Смотреть стор первым делом.
